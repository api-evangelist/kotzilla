TL;DR Freezes (ANRs) were the main stability challenge for Bankin', and existing monitoring or crash reporting tools could not explain them Kotzilla identified the screens and components behind them. ANRs fell 78% and screen rendering time 46% within a few releases Kotzilla is now part of each release: slow screens are identified before they freeze, and Claude Code proposes fixes weekly through the Kotzilla MCP Server
